# Train and Export Demand Model Manually

## Purpose

This guide explains how to run the complete demand model training pipeline
manually from an existing JSON dataset.

This command is intended for local development, model experimentation and
verification without creating a training job through RabbitMQ.

For on-demand training, see
[Run the Model Training Worker](run-model-training-worker.md).

## Prerequisites

Install the training dependencies:

```bash
cd training
poetry install
```

Make sure the training dataset exists at:

```text
training/data/raw/sql_export.json
```

The file must be generated by the SQL export process and conform to:

```text
training/src/training/data/contract.json
```

The training process uploads the resulting model bundle to S3-compatible
storage. Start MinIO from the repository root:

```bash
docker compose up -d s3
```

Make sure the required S3 variables are available in `.env`.

## Run Training

From the `training` directory, run:

```bash
poetry run python -m training.main
```

On Windows, the local virtual environment can also be used directly:

```powershell
.\.venv\Scripts\python.exe src/training/main.py
```

## Training Flow

The command performs the complete offline training flow:

1. Loads demand data from the JSON file.
2. Splits data chronologically into training, validation and final test parts.
3. Compares the supported XGBoost objectives.
4. Selects the best objective using backtest metrics.
5. Runs walk-forward backtesting.
6. Compares XGBoost against the Lag-14 baseline.
7. Reports global, per-category and per-PLU metrics.
8. Evaluates 1-day, 7-day and 14-day prediction windows.
9. Evaluates the selected configuration on the untouched final test set.
10. Trains the production model on all available data.
11. Exports the production model bundle.
12. Uploads the model bundle to S3-compatible storage.

## Local Artifacts

The production bundle is saved locally to:

```text
training/artifacts/production
```

Expected files:

```text
xgb_model.json
preprocessor.joblib
cleaner_artifacts.json
metadata.json
```

## S3 Upload

The bundle is uploaded under the prefix configured by:

```text
MODEL_BUNDLE_S3_PREFIX
```

The default prefix is:

```text
demand-model/latest
```

## Artifact Meaning

`xgb_model.json` contains the trained XGBoost model.

`preprocessor.joblib` contains the fitted model preprocessor.

`cleaner_artifacts.json` contains fitted historical cleaning artifacts,
including winsorization thresholds.

`metadata.json` contains the selected objective, tree count, cleaning
configuration and other model metadata.

## Notes

The untouched final test set is used only for evaluation.

After evaluation, the production model is trained again on all available data
using the selected configuration.

The exported bundle is intended to be loaded by the inference service.
