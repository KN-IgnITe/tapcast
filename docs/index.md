- [Explanations](explain/README.md): Understanding-oriented discussion
- [How-To Guides](how-to/README.md): Goal-oriented directions
- [References](reference/README.md): Information-oriented technical descriptions
- [Tutorials](tutorial/README.md): Learning-oriented experiences
