# Architecture Decision Records (ADRs)

This section contains Architecture Decision Records. ADRs document the structured architectural and technical decisions made in this project, including the context, the decision itself, and the expected consequences.

When making an ADR, you should follow the template provided in the ADR Template (`_template.md in this directory`). Each ADR should be stored in a separate markdown file within this directory, with a filename that includes the date and a short descriptive title (e.g., `20240401-use-kafka-for-event-streaming.md`).
